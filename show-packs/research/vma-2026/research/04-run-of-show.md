## Method and reliability note

WebFetch against every relevant news domain (paramountpressexpress.com, mtv.com, billboard.com,
variety.com, deadline.com, rollingstone.com, tvinsider.com, en.wikipedia.org, thefutoncritic.com)
was blocked by this environment's network egress proxy. Every fact below was therefore obtained
through web search, which returns publisher-indexed article text and press-release text but not the
full page. Source URLs are recorded for later direct verification. Where a claim rests only on a
secondary outlet rather than a Paramount Press Express release or a tier-one trade, it is marked
UNCONFIRMED.

This packet was assembled six days before the telecast. The announcement cycle was still open on the
date checked: both the Madonna release and the additional-performers release close with language
that more performers, presenters and special guests will be revealed. Expect this file to be
incomplete on presenters in particular, and re-run the sweep on September 25 and 26.
